# shon

Blog editorial sobre diseño, cultura y bienestar cotidiano.

🌐 **Visitá el blog:** https://shonydev.github.io/blog/

## Requisitos

- Node.js 20.19+ o 22.12+
- npm

## Desarrollo

```bash
npm install
npm run dev
```

## Producción

```bash
npm run build
npm run preview
```

## Stack

- React 19
- TypeScript
- Vite 6
- Tailwind CSS 4 (plugin oficial para Vite)
- Lucide React

El primer artículo es una introducción al Feng Shui desde una perspectiva cultural y de diseño cotidiano.
